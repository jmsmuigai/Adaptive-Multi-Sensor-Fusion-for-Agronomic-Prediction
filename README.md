**An Attention-Weighted Hybrid CNN–RBF Model for Soil Nutrient Prediction Across East African Agro-Ecological Zones**

Department of Computing, School of Computing and Information Technology,

Reproducibility package for the manuscript submitted to the *Journal of Agriculture, Science and Technology* (JAGST), Manuscript ID 1231; resubmitted as ID 1283.

## What this is

A complete, auditable pipeline that predicts thirteen soil physicochemical properties from mid-infrared (MIR) diffuse reflectance spectra, using 1,310 georeferenced samples from 16 Africa Soil Information Service sentinel sites in Kenya, Ethiopia, Tanzania and Uganda.

Everything in the manuscript — every table, every figure, every number in the text — is generated by the code in `src/` from the two openly licensed source datasets. `src/verify_final.py` re-derives all 109 numeric claims from the stored per-fold records and fails loudly if any has drifted.

There are no machine-learning framework dependencies. All models are implemented in NumPy, so results are not subject to version drift in a deep-learning library and the pipeline runs from a bare Python installation.

## The proposed architecture

```
MIR spectrum (1,749 bands)
        │
   preprocessing        Savitzky–Golay 1st derivative → SNV → binning → standardise
        │                (all fitted inside the training fold)
        ▼
   Conv1D + ReLU + MaxPool  ×2        ──►  H ∈ ℝ^(p×C)
        │
        ▼
   DAFM: additive attention over SPECTRAL POSITIONS
        αⱼ = softmax(vᵀ tanh(W hⱼ + b)),   zₛ = Σⱼ αⱼ hⱼ
        │                                    ancillary inputs (depth, position)
        │                                              │
        │                                         dense encoder → z_c
        ▼                                              ▼
            learned modality gate  g = softmax(W_g [zₛ ; z_c] + b_g)
                              │
                              ▼
        differentiable RBF head   φᵢ = exp(−γᵢ pᵢ²),   ŷ = W_o φ + b_o
```

Three design choices matter:

- **Attention is over spectral positions, not latent channels.** Each weight maps to a contiguous wavenumber window, so it is attributable to an identifiable absorbance region. Attention over latent channels admits no such mapping.
- **The gate is a measured output.** `branch_gate()` returns how much of each prediction came from spectra versus ancillary information, with fold-level uncertainty.
- **The RBF head is bounded.** Since 0 < φᵢ ≤ 1, the prediction satisfies |ŷ − b_o| ≤ ‖W_o‖₁ for any input. The model cannot diverge on data unlike its training set — it reverts toward its bias term instead. This is proved in Section 2.4.5 of the manuscript and confirmed empirically in Table 6.

The head is **not** a support vector regressor. It has no ε-insensitive loss, no margin, no dual coefficients and no support vectors.

## Data

Both deposits are open access and require no account.

| Dataset | DOI | Contents |
|---|---|---|
| MIR spectra | [10.34725/DVN/QXCWP1](https://doi.org/10.34725/DVN/QXCWP1) | 1,749 wavenumbers, 601.7–4001.6 cm⁻¹, one file per country |
| Wet chemistry | [10.34725/DVN/66BFOB](https://doi.org/10.34725/DVN/66BFOB) | 13 properties, GPS coordinates, 2,002 samples across 18 countries |

Joined on soil sample number (SSN) with **zero attrition** — all 1,310 chemistry records for the four study countries matched a spectrum.

## Experimental protocol

- **Seed** `20260804`, governing fold assignment, bootstrap sampling, weight initialisation and minibatch shuffling.
- **Three nested, group-disjoint validation designs.** Leave-cluster-out (207 clusters, 5 folds), leave-site-out (16 sentinel sites, 8 folds), leave-country-out (4 countries, 4 folds). No random splitting is used anywhere.
- **Fold 0 is reserved for hyperparameter selection** in every design and never used as a test fold.
- **Equal tuning budget.** Every model receives exactly three candidate configurations, scored identically.
- **Fold-local preprocessing.** Median statistics, band standardisation, target scaling and the log-transform decision are all fitted on training rows alone.
- **Metrics** R², RMSE, MAE, bias and normalised RMSE, each with fold standard deviation and a t-based 95% confidence interval.

## Headline results

Mean R² across the thirteen properties, best model per design:

| Validation design | Withheld unit | Best mean R² |
|---|---|---|
| Leave-cluster-out | sampling cluster | 0.749 |
| Leave-site-out | 10 × 10 km sentinel site | 0.351 |
| Leave-country-out | national dataset | 0.205 |

Within landscapes: total N 0.939, pH 0.916, total Fe 0.915, eCEC 0.906, exchangeable Ca 0.900, organic C 0.897.

**The main finding is that calibration breadth matters more than model choice.** Restricting the same analysis to three Kenyan sites gives negative mean R² for every model under leave-site-out; the four-country calibration reaches 0.351 and retains positive skill for 12 of 13 properties. Olsen phosphorus moves from R² = 0.164 to 0.562.

We report honestly that the proposed architecture ranks fifth of six within landscapes and mid-pack under transfer, while achieving the best mean R² of all six models when Kenya is withheld entirely (0.240), and the second-least-severe worst-case failure of any model under leave-site-out (−0.43 against −24.15 for the multilayer perceptron on identical features).
